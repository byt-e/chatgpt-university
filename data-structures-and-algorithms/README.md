# Data Structres and Algorithms
A study of data structures and algorithms with directed learning from ChatGPT. 

**Structure Overview:**

- Week 1: Introduction + Arrays & Linked Lists
- Week 2: Stacks, Queues, and Recursion
- Week 3: Trees & Binary Search Trees
- Week 4: Hash Tables and Hashing
- Week 5: Sorting Algorithms (Insertion, Merge, Quick)
- Week 6: Searching & Binary Search, Complexity Analysis
- Week 7: Graphs, DFS/BFS
- Week 8: Review + Capstone Challenge

**Each week will include:**

- Core reading/concepts
- Code implementations in C
- Quizzes or reflections
- One larger problem to solve
- Recommended visualizations/videos
